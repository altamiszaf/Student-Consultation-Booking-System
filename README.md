## Project Description
A web-based **Student Consultation Booking System** designed to eliminate scheduling conflicts, overlapping appointments, and missed messages common in traditional communication channels (such as WhatsApp, email, or face-to-face walk-ins). The system streamlines consultation requests for students while providing lecturers with an efficient management dashboard to publish available time slots, approve or reject requests, select consultation modes (Face-to-Face or Online with meeting links), and prevent double-booking.
